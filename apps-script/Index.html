Como ligar
  • Arraste do ponto direito de uma peça até outra peça.
  • Clique numa peça para escrever as instruções dela.
  • Clique num fio para selecioná-lo; clique de novo ou Del para cortar.
  • Del apaga a peça selecionada.
  • Ctrl+D duplica a peça, com instruções e barra.
  • Ctrl+Z desfaz · Ctrl+Shift+Z refaz.
  • Arraste o fundo para andar · role para dar zoom.
