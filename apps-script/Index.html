Peças

Entrada O pedido que o usuário fornece ao rodar. Opcional, no máximo uma por grafo.
Trabalhador Produz uma parte do trabalho.
Supervisor Avalia só o resultado e manda refazer quando não aprova.
Entrega Junta os resultados que chegam num único artefato.

Como usar

  • Arraste da bolinha direita de uma peça até outra para ligar as duas.
  • Clique numa peça para escrever as instruções dela.
  • Clique num fio para selecionar. Clique de novo para cortar.
  • Del apaga e Ctrl+D duplica a peça selecionada.
  • Ctrl+Z desfaz e Ctrl+Shift+Z refaz.
  • Arraste o fundo para mover o quadro e role para dar zoom.

Quadro vazio

Arraste peças da coluna da esquerda e ligue umas às outras, ou abra um grafo de exemplo para ver como funciona.
